# فاحص الأسعار الذكي - ماركت خيرات الرحمن

**فاحص الأسعار الذكي** هو مشروع ويب مخصص لماركت خيرات الرحمن. يخلّي الزبون يفحص سعر أي منتج من خلال الكاميرا أو كتابة رقم الباركود على هاتفه، ويقدر يشارك رأيه بالسعر أو يرسل شكوى وطلب منتج غير متوفر. المشروع خفيف وما يحتاج تثبيت تطبيق، وينفتح مباشرة من المتصفح.

## فكرة المشروع

مرات الزبون يواجه صعوبة ويضيع وقته حتى يعرف سعر منتج أو حالة توفره، خصوصاً إذا كان الباركود ما يشتغل أو بطاقة السعر مو واضحة. سوينا هذا الموقع حتى يحوّل هاتف الزبون إلى قارئ أسعار سريع:

1. الزبون يمسح رمز QR المعلّق بالماركت.
2. يفتح الموقع على متصفح الهاتف.
3. يمسح باركود المنتج بالكاميرا أو يدخله يدوياً.
4. يظهر اسم المنتج وقسمه والسعر بالدينار العراقي وحالة الكمية.
5. الزبون ممكن يقيم السعر ويرسل ملاحظاته أو يطلب منتجاً غير متوفر.

## شنو سوينا بالمشروع؟

### واجهة الزبون

- مسح باركود المنتجات باستخدام كاميرا الهاتف.
- إدخال رقم الباركود يدوياً للدخول السريع أو عند ضعف الإضاءة.
- عرض معلومات المنتج والسعر وحالة المخزون.
- تقييم السعر بخياري "مناسب" أو "مرتفع".
- إرسال تقييم تجربة التسوق، سواء راضي أو عادي أو غير راضي.
- إرسال طلب توفير منتج وكتابة ملاحظات عنه.
- واجهة متجاوبة تناسب الهواتف والشاشات الصغيرة.

### لوحة الإدارة

لوحة الإدارة مخفية وما يظهر لها زر أمام الزبائن:

- فتح اللوحة بضغطة عنوان الماركت خمس مرات خلال ثانيتين، ثم إدخال الرمز السري.
- إضافة منتج جديد أو تحديث بيانات منتج موجود.
- تغيير الاسم والقسم والسعر والكمية.
- حذف المنتجات من جدول الإدارة.
- استيراد عدة منتجات دفعة واحدة من ملف CSV.
- تصدير قاعدة المنتجات والتقييمات والطلبات بصيغة JSON.
- عرض تقييمات الأسعار والشكاوى وطلبات المنتجات.
- مسح سجل التقييمات والطلبات أو قفل لوحة الإدارة.

## التقنيات المستخدمة

- **HTML5** لبناء صفحات الموقع والنماذج والجداول والنوافذ المنبثقة.
- **CSS3** للتنسيق والتصميم المتجاوب والألوان والتدرجات.
- **JavaScript (Vanilla JS)** لمعالجة البحث وإدارة الواجهة والمنتجات والتقييمات والملفات.
- **Local Storage** لحفظ قاعدة المنتجات وسجل التقييمات والطلبات داخل متصفح الجهاز.
- **HTML5 QR Code** لتشغيل الكاميرا وقراءة الباركود. المكتبة محمّلة من CDN.
- **QRCode.js** لتوليد رموز QR الخاصة برابط الموقع للطباعة. المكتبة محمّلة من CDN.
- **CSV و JSON** لاستيراد وتصدير البيانات.
- **GitHub Pages** لنشر المشروع كموقع ثابت وآمن عبر HTTPS.
- **لا يوجد Backend أو قاعدة بيانات خارجية** حالياً؛ جميع العمليات تتم في المتصفح.

## هيكل ملفات المشروع

```text
market/
├── index.html       # واجهة الزبون ولوحة الإدارة
├── style.css        # تنسيقات الموقع والتصميم المتجاوب
├── products.js      # بيانات المنتجات المبدئية والرمز السري
├── app.js           # البحث والباركود والإدارة والتخزين المحلي
├── qr-maker.html    # صفحة توليد رمز QR للطباعة
└── README.md        # شرح المشروع وطريقة التشغيل
```

## تشغيل المشروع محلياً

1. احفظ مجلد المشروع على الجهاز.
2. افتح ملف `index.html` من المتصفح مباشرة للتجربة العامة.
3. لتشغيل الكاميرا بشكل كامل، الأفضل نشر الموقع عبر HTTPS؛ أغلب المتصفحات لا تسمح بالكاميرا على روابط HTTP غير آمنة.
4. المشروع يطلب الكاميرا الخلفية عند توفرها من خلال إعداد `{ facingMode: "environment" }`.

يمكن تشغيل المشروع من بيئة Local Server بدلاً من فتح الملف مباشرة، مثل إضافة Live Server في VS Code أو أي خادم ملفات ثابت.

## النشر على GitHub Pages

1. أنشئ مستودعاً عاماً على GitHub وارفع ملفات المشروع.
2. ادخل إلى **Settings** ثم **Pages**.
3. اختار الفرع `main` كمصدر للنشر.
4. احفظ الإعدادات حتى تحصل على رابط HTTPS للموقع.
5. افتح `qr-maker.html` والصق رابط الموقع المنشور.
6. اطبع رمز QR وعلقه على مداخل الماركت أو الممرات والأرفف.

## دخول لوحة الإدارة

- اضغط على عنوان الماركت بالموقع خمس مرات متتالية خلال ثانيتين.
- أدخل الرقم السري.
- الرمز الافتراضي موجود في ملف `products.js` وهو:

```text
1234
```

للتغيير، عدل قيمة `ADMIN_PIN` داخل ملف `products.js`.

> تنبيه: رمز PIN الموجود في الجافاسكربت حماية واجهة فقط، وليس حماية أمنية قوية. إذا استخدم المشروع مع بيانات حقيقية أو يحتاج مستخدمين مختلفين، يفضل لاحقاً ربطه بنظام تسجيل دخول وسيرفر وقاعدة بيانات حقيقية.

## تخزين واستيراد البيانات

المنتجات تحفظ تحت المفتاح `khairat_products`، وسجل التقييمات والطلبات تحت المفتاح `khairat_logs` في Local Storage الخاص بالمتصفح.

صيغة ملف CSV المطلوب استيراده:

```csv
barcode,name,category,price,stock
6281011,حليب مجفف,الألبان,5000,40
6281012,قهوة سريعة,المشروبات,3000,25
```

صيغة التصدير تكون JSON وتشمل اسم الماركت والعملة والمنتجات وسجل التقييمات والطلبات.

## المنتجات التجريبية

يوجد بالمشروع عشرة منتجات مبدئية، مثل:

| الباركود | اسم المنتج | السعر |
|---|---|---:|
| 6281001 | زيت طبخ نباتي 1 لتر | 2500 د.ع |
| 6281002 | تمن عنبر درجة أولى 5 كغم | 11500 د.ع |
| 6281003 | شاي أسود فاخر 500 غم | 4000 د.ع |
| 6281004 | سكر أبيض ناعم 2 كغم | 2250 د.ع |

المنتجات موجودة داخل `initialDB` بملف `products.js`، وتستخدم كتجهيز افتراضي إذا ما توجد نسخة معدلة في Local Storage.
